## Original description

Migrates the harness from `0.1.0-rc.7` to `0.1.1-rc.2` (npm `latest`), installed via **pnpm dlx** because npm 11's resolver hangs indefinitely on this Node 25 box for every dsh release past rc.7 (verified: `npm install` never completes, `--dry-run` included; pnpm resolves in ~50s and serves a working cockpit).

Audited with **audit-lite between slices** and a **5-role GauntletGate Full** panel. Every finding fixed and mutation-proven.

## The one that mattered most (found by the panel)
**PE-M1** — the `maxConcurrentJobsPerOwner: 1` cap I'd added as the fix for the 2026-08-20 fan-out disaster **never attached**, on rc.7 or 0.1.1. The patch used `id: jobs-local` but the base composes as `id: jobs` (package dsh-jobs-local, entry id jobs). `dump-config` said `patch: entry "jobs-local" not found` and every gate missed it (they grepped `warn|unmatched|error`, not "not found"). **Fixed the id (verified the cap now attaches), broadened all three gates to fail on "not found", and rewrote test A2 to assert the correct id.**
