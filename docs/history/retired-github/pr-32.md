## Original description

Two agents on this machine ran reddit-search at the same time today, each pacing correctly at 8s, and both hit 429s - because Reddit rate-limits per IP, not per agent. Two polite clients on one connection are one impolite client. The skill now tells the agent to check whether another session is doing Reddit work and wait rather than interleave. Also captures the XmlElement parsing trap the local model had to work out at runtime, and adds guidance to discover the right subreddit by searching all of Reddit first instead of guessing names.
