## A. Armed on the live box — all four were the *same* failure waiting to recur

The 2026-08-20 disaster was five subagents queueing on a model that serves one prediction at a time. Three defaults kept that armed, by three separate doors:

| Defect | Was | Now |
|---|---|---|
| workflow `maxConcurrentAgents` | unset → engine resolves 0 to **CPU count** (~16 children, one lane) | `1` |
| `maxTotalAgents` | unset — and it **cannot** be set from a workflow script | `64` in the preset |
| `jobs-local` per-owner cap | 10 background children, no workflow tool needed | `1` |
| `retryPolicy` | unset → **5 retries**, each re-prefilling the full context | `maxRetries: 1` |
| `compactionRetries` | 2, raised without justification | reverted to 1 |

PR #41 lengthened the idle timeout and left `retryPolicy` alone — that treated the symptom. Five retries re-prefilling 131,072 tokens is how one turn consumed **2,396,400 input tokens**.
