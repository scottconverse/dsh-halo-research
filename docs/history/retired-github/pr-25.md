## Original description

Fills the empty space on Overview with the thing the console genuinely lacked: **history**. Every other card is a point-in-time reading; none of them can tell you whether something is trending wrong. The 60-second history (2,111 rows spanning 39 hours) was already being collected and was only ever rendered as a 220px sparkline.

**Machine vitals** (full-width card): GPU dedicated as a filled area with GPU **shared stacked on top** - chosen deliberately, because shared-pool growth is the OOM leak signature and stacking makes a sliver-vs-band read instant. Decode t/s on its own right-hand axis, with the line broken across idle periods rather than drawing a straight lie. Hover gives a crosshair and exact values at that moment. Ranges 1h / 6h / 24h / 7d, with the time-axis format switching to date+hour on long ranges. Six live readouts above the chart: decode rate, GPU dedicated vs carveout, shared pool, Windows free RAM, fullest session context, models generating now - each colouring amber/red at its own threshold.

Backend: `/api/history?hours=N`, downsampled to 400 points (past that a chart this size draws noise), tolerant of the `GB`->`GiB` field-name drift that happened mid-record so the older half of the history is not lost.

Also fixes the fair complaint on the context column: the token counts were hidden in a tooltip and a click-through. They are now visible in the cell - used / window / remaining - with the percentage badge as the fast read.

Verified live: full-width render (1217px card), all four ranges, hover crosshair and tooltip, threshold colouring, legend collision-free, and correct downsampling (2,111 rows -> 354 points at 7d).
