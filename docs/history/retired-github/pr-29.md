## Original description

Four of six tab reviews led with the same finding: the UI is uniformly green, so a tired operator has nothing to scan for and an all-green screen can be lying. This addresses that across the board - a CONTEXT signal in the alarm strip (which previously claimed nominal while ignoring the one risk the Sessions tab tracks), colour-ramped context percentages starting at 50%, severity-coloured gauge bars with stated denominators, and a Plugins tab where the 31 non-active rows are reachable by clickable count chips and sorted to the top instead of buried behind 135 identical green ones.
