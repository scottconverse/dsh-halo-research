# v0.3.17 — Windows installer 0.1.3

Windows installer **0.1.3** adds the full-memory and 32K capped Halo Strata presets, the 5070 Ti SSH worker, and separate lead-only Browse variants for DSH Web and Desktop. It keeps Web and the official Desktop application on DSH 0.2.2-rc.1 and includes embedded Desktop Mission Control.

The installer sets up a dedicated headless Chrome for Testing profile. Browse starts when requested and is exposed only in the two Browse lead presets. Strata uses operator-provided engines, launch files, model assets, and SSH credentials. Setup downloads no model weights and invokes no model. Install alongside an existing setup in a new destination.
