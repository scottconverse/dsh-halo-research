Why it exists

Most routing skills sort by price per token. Inside DSH that optimises the wrong variable: the session model is already paid for, so its marginal dollar cost is zero. What actually costs you is wall-clock and rework.

This skill optimises cost per accepted item — and it makes “accepted” a command's exit code, not an opinion.

Three lanes

LANE 1 · DEFAULT

Self

The DSH session model does the work. Effort is behavioural here: E1 run the tests, E2 write an oracle first, E3 independent verification. No quota, no setup.

LANE 2 · FREE BATCH

Local Ollama

Homogeneous, checkable, private work. Parallel 1–2. Local weights are free; one cloud model is allowed and priced as an estimate.

LANE 3 · EXCEPTION

External

claude -p and codex exec. Paid, slow to integrate, and only for a capability ceiling, a named-risk audit, or a worktree delegation.

The escalation test

external_worth_it =
      self_failed_acceptance_twice
   or task_in_known_weak_class        # exact/dense algorithms
   or irreversible_high_stakes        # auth, migrations, deletion
   or (wallclock_critical and ext > 4x faster and task >= 1 hour)
  and can_verify_the_output           # no oracle, no delegation
  and est_external_cost < value_of_time_saved

The load-bearing clause is can_verify_the_output. If you cannot check what comes back, an external model is just a more confident guess.

Five commands

./scripts/route.ps1 probe
./scripts/route.ps1 call  -Route local -Model qwen3.8:27b-q4_K_M `
                          -PromptFile prompt.txt -Task summarize -Class docs
./scripts/route.ps1 accept -Task summarize -Cmd "pytest -q"
./scripts/route.ps1 report -ByClass
./scripts/route.ps1 settings -Model deepseek-v4.1-flash:1017-cloud

One call, one ledger line, one receipt. Acceptance is recorded by a command's exit code, so report can compute cost per accepted item.

What it refuses to do

  • Escalate for style, tone, or “a second opinion” with no named risk.
  • Send a batch to a paid lane — batch refuses external and cloud-tagged models.
  • Let an external model be the last reader: it proposes a patch, you review and apply it.
  • Invent a cost. Codex returns a single token count, so its cost stays n/a rather than guessed.
